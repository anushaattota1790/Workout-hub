# My PT Hub - Workout Manager

A mobile-friendly workout and home exercise tracking system with integrated YouTube demo links.

## Contents

- **Workout Plans**: 5 gym workout days + 5 home workout routines
- **Diet Plans**: Non-veg and vegetarian meal plans
- **Demo Videos**: Clickable YouTube exercise demos from @MyPTHub channel
- **Print-Friendly**: Day 5 workout layout optimized for printing

## Quick Start

1. Open `hub.html` on your phone
2. Tap any workout to open the PDF
3. Tap the "▶ Watch" button next to each exercise to see demo videos
4. Add hub.html to your home screen for quick gym access

## Features

- Mobile-responsive design
- Direct PDF access to all workout plans
- Integrated YouTube links for exercise demonstrations
- One-tap home screen launcher (iOS/Android)

## Files

- `hub.html` — Main navigation hub (start here on mobile)
- `index.html` — Day 5 workout print layout
- `styles.css` — Shared styling
- `*.pdf` — Workout and diet plan files
- `pdf_backups/` — Backup copies of modified PDFs
